# UI style question bank

Use these examples to draft one question at a time, not a fixed survey.
Choose 3–5 axes per layer for a full interview.
Start with the four listed axes for each layer and substitute or add relevant axes as needed.
Omit axes that a fixed requirement already settles, and replace them with unconstrained ones.
If a narrow scope leaves fewer than three meaningful axes in a layer, use a targeted refinement instead of padding the interview.
The letter order below is illustrative; do not imply that one choice is the recommended style.

## Overall / macro

Render the same complete screen in each option.

| Axis | Three visual directions | Keep fixed |
| --- | --- | --- |
| Page composition | Centered column / asymmetric split / equal-width grid | Content, palette, typography, and component styles |
| Section rhythm | Compact / balanced / spacious gaps between major sections | Internal component padding and font sizes |
| Visual emphasis | Heading-led / data-led / action-led | Information order and available actions; vary the distribution of visual emphasis |
| Use of accent | Only on the primary action / on actions and section markers / also on lead surfaces | The chosen accent hue, content, and layout |

## Components / meso

Carry the settled page rules forward and render one representative section or task.

| Axis | Three visual directions | Keep fixed |
| --- | --- | --- |
| Grouping | Open rows / divided groups / individual cards | Information, actions, and visual weight of the content |
| Navigation treatment | Underline / pill highlight / side marker | Navigation order, active destination, and placement; pick treatments that fit the existing navigation axis |
| Action treatment | Filled primary / outlined primary / text primary with a clear marker | Labels, positions, action priority, and target sizes |
| Component density | Compact / regular / roomy internal spacing | Gaps between major sections and the minimum accessible target sizes |

## Details / micro

Use a close-up that still shows how the detail works in context.

| Axis | Three visual directions | Keep fixed |
| --- | --- | --- |
| Corner shape | Square / softly rounded / asymmetric | Card and button dimensions, border, color, and content |
| Palette | Cool blue and slate / warm clay and cream / muted green and stone | Semantic color roles, legibility, and the established distribution of accent |
| Heading letter spacing | Tighter / neutral / wider | Typeface, size, weight, and body text; pick a feature that has a visible effect in the actual script |
| Border treatment | No visible border / fine line / heavier line | Depth, fill, and geometry; use nonessential surface borders rather than focus indicators |

For corner shape, show it in both a card and its action if that helps the user compare.
If the user wants a more rounded follow-up, show regular radius, large radius, and pill-shaped actions with all other properties held constant.
For palettes, show background, surface, text, and action colors in the actual components, not just as swatches.
Name the palettes and their roles in text so hue is not the only cue.
Confirm exact colors in this layer without reopening macro accent placement unless the user requests it.
