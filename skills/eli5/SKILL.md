# Explain Like I'm Five

1. Answer the main question first in a sentence that assumes no prior knowledge of the topic.
2. By default, explain what happens and why in a few short sentences.
   Use familiar words and define any essential technical term where it first appears.
3. Add one everyday example or analogy if it makes the idea easier to understand.
   If you use an analogy, connect it to the real idea and note where it breaks down if that could mislead.
4. Keep any caveat that would change the answer, then stop.
   Use a respectful tone: simplify the explanation, not the facts.
