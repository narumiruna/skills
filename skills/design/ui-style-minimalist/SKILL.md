# Minimalist

僅在使用者明確選用此風格時，套用至指定的 Web app 總覽或儀表板畫面。
保留既有的產品行為、品牌要求、文字對比、可見的鍵盤焦點和必要的操作目標尺寸。

## 整體

- 空間足夠時，將兩個主要區塊排成等寬雙欄；空間不足時，依內容順序改為單欄。
- 在頁面標題列與主要區塊之間保留 `2rem` 的垂直間距。
- 以 `1.875rem`、字重 `750` 的頁面標題作為主要視覺焦點，讓列表項目與操作標籤保持次要。
- 只將強調色用於主要操作和主要區塊的標題；頁面標題列與其他主要表面維持中性色。

## 元件

- 總覽列表採開放式排列，只用空白區隔項目，不加群組外框、列分隔線或單項卡片。
- 列表項目上、下各留 `0.25rem` 內距，不縮小必須保留的操作範圍。
- 水平導覽用底線標記目前頁面，並保留獨立的鍵盤焦點指示。
- 主要操作使用中性色背景，外框、文字和既有圖示使用強調色，不使用強調色實心填滿。

## 細節

- 只為主要操作設定 `0.375rem` 圓角。
- 頁面標題使用字體預設字距（`letter-spacing: normal`）。
- 在淺色模式下，於頂部導覽下方加一條 `1px`、`#7c887a` 的分隔線。
- 使用 Green and stone 淺色配色：
  - 頁面背景：`#edefe7`。
  - 內容表面：`#fbfcf7`。
  - 主要文字：`#222a21`。
  - 次要文字：`#52614e`。
  - 強調色：`#356245`。
