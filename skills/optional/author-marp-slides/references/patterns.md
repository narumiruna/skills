# Common Slide Patterns

Pick one pattern per slide. Do not mix layouts unless the slide needs it.

## Title

```markdown
# Presentation Title

Subtitle or presenter
```

## Agenda

```markdown
# Agenda

1. Problem
2. Approach
3. Result
```

## Problem / Solution

```markdown
# The Problem

- Current pain
- Cost or risk
- Why now

---

# The Solution

- New behavior
- Why it works
- Proof point
```

## Split Image + Text

```markdown
![bg right:45% fit](assets/diagram.svg)

# Architecture

- Point one
- Point two
```

## Before / After

```markdown
# Before / After

| Before | After |
| --- | --- |
| Manual | Automated |
| Slow | Fast |
```

## Code + Explanation

````markdown
# Key Change

```python
result = transform(input)
```

- What changed
- Why it matters
````

## Section Divider

```markdown
<!-- _class: lead invert -->

# Part 2
```

## Q&A

```markdown
<!-- _class: lead -->

# Questions?
```
